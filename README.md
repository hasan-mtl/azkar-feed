# আযকারুল মুওয়াহহিদীন: বার্তা ও আপডেট

আযকারুল মুওয়াহহিদীন অ্যাপের বার্তা, রিমাইন্ডার ও আপডেটের একটি কপি। অ্যাপটি এখান থেকে নতুন বার্তা ও নতুন দো‘আ পড়ে নেয়,
